# Учебные работы — Портфолио

Репозиторий содержит выполненные лабораторные работы по веб-разработке.

## 📋 Содержание

### Task 01 — Резюме / Проекты
Адаптивная страница-резюме с портфолио проектов и контактной формой.

**Технологии:** HTML5, CSS3, семантическая вёрстка, адаптивный дизайн

**Особенности:**
- Семантическая разметка (header, nav, main, section, footer)
- Адаптивная навигация
- Переключатель темы (светлая/тёмная)
- Форма обратной связи
- Оптимизированные изображения (AVIF)

📂 [Перейти к работе](task_01/src/)

### Task 02 — Каталог уроков
Интерактивный каталог учебных материалов с табами, модальными окнами и формой вопросов.

**Технологии:** HTML5, CSS3, JavaScript (ES6+), DOM API

**Особенности:**
- Табы для переключения между темами
- Модальные окна для просмотра уроков
- Делегирование событий
- Клиентская валидация формы
- Доступность (ARIA-атрибуты)

## 🚀 Как запустить

### Локально
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/alexsandro007/all_tasks_v23.git
   cd all_tasks_v23
   ```

2. Откройте `index.html` в браузере или запустите локальный сервер:
   ```bash
   python -m http.server 8000
   ```
   Затем откройте http://localhost:8000
